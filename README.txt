VIRTUAL COIN PUSHER - UNITY 3D PROJECT (v3 - Realistic Arcade Edition)

WHAT'S NEW IN v3:
- Procedural high-detail textures (quarters, casino poker chips with edge spots, strapped cash stacks, stamped 1oz gold bars, brushed steel pusher, arcade deck).
- Realistic arcade cabinet: glowing LED neon pillars, chrome trim, transparent front glass, physical coin hopper tray, and multi-point arcade lighting.
- Realistic rounded wireless earbud charging cases (with lid seam & status LED).
- Permanent UI layout fix for the Hopper screen and Top HUD.

HOW TO UPDATE YOUR EXISTING PROJECT (FASTEST):
1. Close or stop Play Mode in Unity.
2. Copy the "Assets/Scripts" and "Assets/Editor" folders from this ZIP into your existing project's "Assets" folder (replace existing files).
3. In Unity's top menu bar, click:
      Tools -> Build Coin Pusher Scene
4. Press PLAY!

OR OPEN AS A NEW PROJECT:
1. Unzip anywhere on your computer.
2. Open Unity Hub -> Add -> Add project from disk -> select "VirtualCoinPusher_Unity".
3. Wait for it to auto-build (or click Tools -> Build Coin Pusher Scene) and press PLAY.
